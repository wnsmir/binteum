웨이팅(Waiting) — 제출용 소개문

1. 앱 한 줄 소개
- 전기차 충전 예상시간 또는 사용자가 설정한 대기시간에 맞춰 영상·음악·주변 장소·수면을 선택하도록 돕는 차량용 앱.

2. 기획 배경
- 충전·정차 중 발생하는 짧고 불규칙한 대기시간에 주목.
- 남은 시간 안에 즐길 콘텐츠나 방문할 장소를 찾기 어려운 불편.
- 여러 앱을 오가며 충전 상태·영상 길이·이동시간을 확인하는 번거로움.
- 차량 정보와 대기시간을 한 화면에서 확인하고 바로 이용할 수 있는 경험 제공.

3. 앱 주요 기능 및 차량 특화 요소
- 다이얼 설정: 시간 또는 목표 잔량을 선택하고 남은 시간을 직관적으로 확인.
- 시간 기반 콘텐츠: 영상·음악·주변 장소·수면을 하나의 세로 화면에서 탐색하고 측면 목차로 바로 이동.
- 영상: 썸네일·재생시간 카드와 같은 화면의 YouTube 플레이어 연결, Netflix 외부 앱·웹 열기.
- 음악: 선호 서비스 선택과 외부 연결, 지원 앱이 없는 시연 환경에서는 휴대폰 QR 제공.
- 주변 장소: 차량 위치를 기준으로 카페·식사·간식·산책 장소와 도보 왕복시간을 조회해 남은 시간과 비교.
- 수면: 남은 시간 동안 검은 화면에 카운트다운과 종료 버튼만 표시. 종료하면 이전 화면으로 복귀.
- 차량 UI: 큰 글자·버튼, 측면 조작 패널, 단색·시간별 배경, 한국어·영어 지원.
- 차량 상태 반영: 제공되는 배터리·충전 정보를 활용하고 주행 제한·상태 미확인 시 콘텐츠 이용 제한.

4. 주요 사용 시나리오
- 충전소에서 대기 중인 운전자가 웨이팅 실행.
- 다이얼에서 시간 20분 또는 목표 잔량 선택 후 시작.
- 남은 시간을 확인하며 영상·음악·주변 장소 중 원하는 콘텐츠 선택.
- 외출을 고려하면 주변 장소의 왕복 도보시간과 체류 여유 확인.
- 쉬고 싶을 때 ‘남은 시간 동안 수면’ 선택.
- 검은 수면 화면에서 남은 시간을 확인하고 ‘종료’를 누르면 원래 화면으로 복귀.
- 시연에서는 ‘모의 충전’을 사용하고 실제 차량 데이터와 구분.

5. 개발 계획
- 현재 구현: Pleos Connect 기반 Android/Kotlin 앱, 타이머·통합 콘텐츠 화면·설정·수면 모드.
- Pleos Vehicle SDK 2.3.2: 배터리·차량 지원 기능 조회, 충전 목표 및 기존 시트 메모리 적용 요청 경로.
- Android Automotive API: 실제 충전 상태·잔여 충전시간·차량 목표·주행 제한·P단/속도 확인.
- Pleos FusedLocation SDK 1.1.3: 차량 위치 수신과 주변 장소 검색 연결.
- YouTube IFrame Player API: 앱 화면 내 영상 플레이어 연결.
- ZXing core 3.5.3: 음악·지도 링크의 휴대폰 QR 생성.
- OpenStreetMap·Valhalla: 현재 대한민국 장소와 도보 경로 제공. 향후 운영 서버와 제공 지역 확대.
- Pleos TextToSpeech SDK 3.3.1: 음성 미리 듣기 경로 구현. 현재 시연 기기에서 출력이 확인되지 않아, 호환 환경 검증 후 음성 안내 제공 추진.
- 음악: 현재 Pleos 시연 환경에 지원 음악 앱이 없어 차량 내 앱 연결 제한. 향후 지원 앱이나 공식 연동 환경 확보 시 계정 인증과 차량 내 연결 확장 가능.
- Netflix: 현재 외부 앱·웹 연결 방식. 공식 재생 방식과 차량 호환성 확보 시 이용 경로 확대 검토.
- 충전 예상시간: 차량에서 정보를 제공하지 않으면 직접 시간 설정으로 이용. 지원 차량별 데이터 검증 확대.
- 시트: 기존 차량 메모리 선택·적용 요청 구현, 실제 이동 검증 필요. 새 자세 저장은 차량 설정을 이용하며 지원 기능 확대 시 연동 범위 확장 검토.
- 수면: 현재 앱 화면이 열린 동안 동작. 차량 실행 정책에 맞는 환경 확보 후 화면 밖 알림 확장 검토.

6. 기대효과 및 발전 가능성
- 핵심 고객: 충전 중인 전기차 운전자와 차량 안에서 정차 대기하는 사용자.
- 제공 가치: 콘텐츠 탐색 부담 감소, 남은 시간에 맞는 선택, 간단한 휴식 진입.
- 현재 출시 전 단계로 MAU·재방문율 실적은 미집계.
- 초기 시연을 통해 추천 선택률·반복 이용률·다음 달 재방문율을 측정하고 수치 목표 구체화.
- 검증된 영상 확대, Pleos 지원 음악 서비스 연결, 지역별 장소 데이터 확장 추진.
- 실제 차량 검증 결과를 바탕으로 충전 예상시간·시트·음성 기능의 적용 범위 확대.
